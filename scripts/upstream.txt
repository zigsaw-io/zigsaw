# Where scripts/check-upstream.sh looks for newer versions of what the recipes
# download. Every source URL in a recipe has to be covered here, which CI checks:
# a recipe with a new source needs a row, and a row nothing uses goes.
#
#   <name> git  <repository> <pattern> [options]      its tags
#   <name> page <URL>        <pattern> [options]      the page's text
#   <name> skip <why>                                 not checked, saying why
#     <source URL>...                                 indented: the sources it covers
#
# A pattern is what's around {version} there, with nothing else in it that varies.
# For git it's the whole tag; on a page, have something after {version} as well,
# or "1.2.3" also matches "1.2.3rc1". In a source URL, {version} is the version
# the recipe pins (the first one, if it's there twice), and * is anything. The
# first row that matches a URL has it.
#
# A version is digits with . _ - or + between them, all compared as dots, so one
# with letters in it counts as a pre-release and is left out. Options:
#   ver=<regex>   what a version looks like here instead (extended regex, no spaces)
#   series=<n>    how many leading numbers make a series (default 2); 0: no series,
#                 every newer version is simply an update
#   even          leave out odd minor versions, some projects' development series
#   exclude=<regex>  leave out versions that match, as compared (with dots): those
#                 a project numbers as pre-releases, or old ones that sort high
#   latest        the page shows only the newest version, so finding the pinned one
#                 can't show the row is right: use only when there's no better page
#   osv=<place>   where OSV (osv.dev) lists this upstream's advisories, instead of the
#                 row's repository; it can be given several times. A `git` row looks in
#                 its own repository, by default, and a `page` row nowhere. A place is
#                 <repository>,<tag>, where {version} in the tag is the version as
#                 compared, {version_} that with underscores, and {sqlite} SQLite's
#                 number as its version (3530400: 3.53.4); or <ecosystem>:<package>,
#                 an OSV ecosystem's (Go:stdlib, crates.io:bat)
#   osv-thin      OSV lists about as little for older releases with known problems, so
#                 that it lists nothing here says nothing: the report says so
#
# A recipe holding on purpose to a series keeps its row, and shows under "Only a
# new series": ICU 72 is Windows' own (PostgreSQL's collations), OpenSSL 3.5 the
# long-term series, Node 24 the LTS, GTK 3 and GtkSourceView 4 what their apps use.
